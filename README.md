# ระบบร่างหนังสือราชการ

ระบบช่วยร่างหนังสือราชการ กลุ่มงานทันตกรรม โรงพยาบาลบางปะอิน ทำงานในเบราว์เซอร์ทั้งหมด

## ทำอะไรได้

- บันทึกข้อความ ขออนุมัติจัดซื้อ จัดจ้าง ซ่อม เช่า
- หนังสือภายนอก ขอความอนุเคราะห์ เชิญชวน ชี้แจง (ส่งหลายผู้รับได้ในครั้งเดียว)
- แนบตาราง (วางจาก Excel ได้) และแนบไฟล์ PDF หรือรูปภาพ
- ดาวน์โหลดเป็นไฟล์ Word (TH Sarabun New 16 pt, กระดาษ A4) ตามรูปแบบระเบียบงานสารบรรณ

## ความเป็นส่วนตัว

เนื้อหาที่กรอกและไฟล์ที่แนบถูกประมวลผลในเครื่องผู้ใช้เท่านั้น ไม่ถูกส่งหรือบันทึกไว้ที่ใด ปิดหน้าเว็บแล้วข้อมูลหายไป

## ข้อกำหนด

- ต้องเชื่อมต่ออินเทอร์เน็ต (โหลดตัวสร้างไฟล์ Word และตัวอ่าน PDF)
- เครื่องที่เปิดไฟล์ Word ควรติดตั้งฟอนต์ TH Sarabun New

## แก้ค่าตั้งต้น

ชื่อผู้ลงนาม ที่อยู่ เบอร์โทร และเลขที่หนังสือ อยู่ในไฟล์ `index.html` ส่วน `DEFAULT_SETTINGS`
แก้ระหว่างใช้งานได้ที่หัวข้อ "หน่วยงานและผู้ลงนาม" ท้ายแบบฟอร์ม (ค่าที่แก้จะไม่ถูกจำเมื่อปิดหน้า)
